# 予定手帖 — セットアップ手順

Googleカレンダー（toukatsu.paint@gmail.com）の予定を、iPhoneで「全部見える月カレンダー」として表示するアプリです。読み取り専用です。

## しくみ

```
Googleカレンダー ──(読むだけ)── Apps Script（Googleの無料サーバー）──JSON──▶ 予定手帖（iPhoneのホーム画面）
```

- **Apps Script**：toukatsu.paint@gmail.com のアカウントで動く小さなプログラム。カレンダーの予定と色IDを読み、アプリに渡します。
- **予定手帖**：GitHub Pages などに置いたWebページ。Safariで開き「ホーム画面に追加」するとアプリとして全画面で開けます。
- iPhone側でGoogleにログインする必要はありません（1時間ごとのログアウトもなし）。
- 合言葉を知らない人は予定を読めません。URLと合言葉は人に教えないでください。

## 手順1：Apps Script を用意する（パソコン推奨・約10分）

1. **toukatsu.paint@gmail.com でログインした状態で** https://script.google.com を開き「新しいプロジェクト」。
2. プロジェクト名を「予定手帖」にする。
3. `apps-script/Code.gs` の中身を丸ごと貼り付ける。
4. `const SECRET = 'ここを好きな合言葉に変更';` を自分だけの合言葉（例：英数字15文字以上）に書き換えて保存。
5. **（必須）** 左の「プロジェクトの設定」（歯車）→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック → エディタに出た `appsscript.json` を `apps-script/appsscript.json` の内容に丸ごと置き換えて保存。これで権限が「カレンダーの閲覧のみ（calendar.readonly）」に固定されます。この手順を飛ばすと、Googleが自動で「カレンダーの編集」まで含む広い権限を求めてしまいます。
6. 上の関数選択で `testRun` を選び「実行」→ 権限の確認が出たら許可する。
   「このアプリは Google で確認されていません」と出たら「詳細」→「予定手帖（安全ではないページ）に移動」→「許可」。自分で作ったものなので問題ありません。
   実行ログに今日の予定が出れば成功です。
7. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー。

> Code.gs を後で直したときは「デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→「デプロイ」。URLは変わりません。

### すでに広い権限で許可してしまった場合（権限を閲覧のみに絞り直す）

1. 手順3〜5のとおり `Code.gs` と `appsscript.json` を貼り直して保存（合言葉は今までと同じものに戻す）。
2. https://myaccount.google.com/connections （サードパーティ製のアプリとサービス）を toukatsu.paint@gmail.com で開き、「予定手帖」→「接続を解除（アクセス権を削除）」。以前の広い許可がここで消えます。
3. エディタで `testRun` を実行 → 許可画面に **「Google カレンダーを使用してアクセスできるすべてのカレンダーの予定の表示」だけ** が出ることを確認して許可。「作成・変更・削除」の文言があれば `appsscript.json` が反映されていません。
4. 「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」。URLは変わらないので、iPhone側の設定はそのままで使えます。

## 手順2：アプリを公開する（GitHub Pages の例）

1. GitHub に新しいリポジトリ（例：`yotei-techo`）を作り、このフォルダの中身（`apps-script` フォルダ以外でOK）をアップロード。
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save。
3. 数分後に `https://ユーザー名.github.io/yotei-techo/` で開けるようになります。

（GitHub を使わない場合は Netlify Drop：https://app.netlify.com/drop にフォルダをドラッグするだけでも公開できます）

## 手順3：iPhone に入れる

1. iPhone の **Safari** で公開したURLを開く。
2. 共有ボタン →「ホーム画面に追加」→「追加」。
3. **ホーム画面のアイコンから開いて**、⚙（設定）にウェブアプリのURLと合言葉を入れて「保存して読み込む」。
   ※ iPhoneでは、Safariで開いた画面とホーム画面のアプリは保存場所が別なので、設定は必ずホーム画面から開いた方で入れてください。URLはLINEやメモで自分に送っておくとコピーが楽です。

## 使い方

- ‹ › または左右スワイプで前月・次月、「今日」で今日に戻る、↻ で再読み込み。
- アプリを開いたとき・戻ってきたとき（1分以上たっていれば）・月を切り替えたときに最新の予定を読み込みます。
- 予定をタップすると詳細（日時・協力会社・場所・メモ）が出ます。
- ⚙ で文字の大きさ（小／中／大／特大）を変えられます。
- 電波がないときは、最後に読み込んだ予定を表示します。

## 協力会社の凡例を設定する

`config.js` の `companies` に、色ごとの会社名を書きます。

```js
'7': '〇〇塗装',   // ピーコック
'10': '△△工業',  // バジル
```

書き換えたファイルを公開先にアップロードし直すと反映されます。会社名を入れた色は、その月に予定がなくても凡例に出ます。

| 色ID | 色名 | 色ID | 色名 |
|---|---|---|---|
| 1 | ラベンダー | 7 | ピーコック |
| 2 | セージ | 8 | グラファイト |
| 3 | ブドウ | 9 | ブルーベリー |
| 4 | フラミンゴ | 10 | バジル |
| 5 | バナナ | 11 | トマト |
| 6 | ミカン | （空） | 色指定なし＝カレンダーの既定色 |

## 表示ルール

- 終日の予定と、日をまたぐ予定 → 週の上部に帯で表示（開始日〜終了日を一本でつなぐ。週をまたぐと ◀ ▶ 付きで次の週に続く）
- 時間のある予定 → 帯の下に時刻順で全部表示（「他〇件」で隠さない。マスが縦に伸びる）
- 今日 → 黄色の背景と青い枠。日曜・祝日は赤、土曜は青
